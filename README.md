## The line

> I don't understand your question — I just pattern-match it against ten thousand similar ones and pray you don't notice.

## How to run

```sh
python3 main.py
```

This writes the line to `entry.txt` under the directory in `ENTRY_OUTPUT_DIR` (default `/output/entry.txt`).

Python standard library only, no network.
